# 소리 미로 · 동물친구들 (wordmaze)

과일 이름을 말하며 아이소메트릭 3D 미로를 통과하는 React/Vite 앱입니다. 원본 동물 12종은 studio의 `public/chars/*.js`를 그대로 사용합니다. 파닉스는 포함하지 않습니다.

## 시작 모드

- **싱글플레이:** 로그인 없이 모든 동물 선택 가능. 개인 최고 기록과 이름·선택 동물은 이 브라우저의 localStorage에만 저장합니다. 싱글 게임은 Supabase를 초기화하거나 게임 결과를 전송하지 않습니다. 브라우저 데이터를 삭제하면 기록이 사라집니다.
- **멀티플레이:** 기존 sudoku와 같은 Supabase 프로젝트에서 Google 로그인. 계정별 최고 기록, 별빛, 동물 구매·선택을 저장합니다. 실시간 동시 대전은 아니며 순위표를 통한 기록 경쟁입니다.
- 영국식/미국식 선택은 기기 예시 음성 및 브라우저 음성인식 언어에 적용합니다. 발음 정확도 점수나 억양 판정은 하지 않습니다.
- 말하기 버튼을 누른 채 읽고 손을 떼면 최종 인식 결과를 확인합니다. 정확한 목표 단어만 통과하고 무음·권한 거절·연결 오류는 통과하지 않습니다.
- 기본 동물은 고양이입니다. 싱글은 모든 동물이 열려 있고 멀티는 별빛으로 구매합니다.

## 보상과 기록

멀티 클리어 보상은 `10 + 스테이지 × 2` 별빛입니다. 기존 개인 최고 기록을 단축하면 10 별빛을 추가합니다. 첫 클리어는 기본 보상만 받고, 삼색고양이는 클리어마다 5 별빛을 추가합니다. 중복 완료 요청이나 이미 보유한 동물의 중복 구매에는 중복 지급·차감이 없습니다.

순위와 개인 기록은 **스테이지 × 영어 설정 × 캐릭터 × 엔진 버전**별로 구분합니다. 서버가 경과 시간을 계산하고 캐릭터의 시간 보너스·쉼표를 반영합니다. 음성인식 대기·네트워크 시간은 포함합니다. 브라우저가 인식 결과를 제출하므로 음성 조작까지 막는 공식 대회용 검증은 아닙니다.

| 동물 | 가격 | 능력 |
|---|---:|---|
| 고양이 | 기본 | 첫 정답 때 1.5초 단축 |
| 곰 | 60 | 한 번 5초 쉬기, 그동안 시계 정지 |
| 토끼 | 90 | 단어 하나 건너뛰기 |
| 강아지 | 70 | 첫 오답 때 2초 단축 |
| 호랑이 | 120 | 3연속 정답마다 2초 단축, 최대 두 번 |
| 펭귄 | 100 | 정답마다 0.25초 단축 |
| 초코푸들 | 80 | 예시 발음을 천천히 두 번 재생 |
| 샴고양이 | 80 | 단어를 나누어 읽는 힌트 |
| 삼색고양이 | 110 | 클리어 보상 5 별빛 추가 |
| 암사자 | 150 | 첫 오답을 한 번 통과 처리 |
| 숫사자 | 140 | 마지막 단어 건너뛰기 |
| 해달 | 100 | 6글자 이상 단어의 첫 정답 때 3초 단축 |

## 실행 및 빌드

Node 22.13 이상 권장. 폴더에서 다음을 실행합니다.

```sh
npm ci
npm test
npm run dev
npm run build
```

`dist/`는 빌드된 정적 앱입니다. 이 폴더 전체를 HTTPS 정적 호스팅에 올리면 됩니다. 상대 경로를 사용하므로 하위 폴더 배포도 지원합니다. GitHub 파일 보기 화면 자체에서는 게임이 실행되지 않습니다.

## Supabase

기존 sudoku 프로젝트 `rxzqlopkrlftbkzxrqmd`의 Auth를 재사용합니다. `src/lib/supabase-config.ts`에는 공개용 anon 키만 있으며 서비스 역할 키나 관리자 자격 증명은 없습니다. 스도쿠의 지갑·게임 데이터는 변경하지 않고, `wordmaze_private` 스키마에서 독립 관리합니다.

`wordmaze_game`, `wordmaze_deny_direct_access` 마이그레이션을 해당 프로젝트에 적용했습니다. SQL 파일은 `supabase/migrations/`에 보관합니다. 이미 적용된 프로젝트에 초기 생성 SQL을 다시 실행하지 마세요. 새 프로젝트에서는 두 마이그레이션 순서대로 적용한 후 공개 설정을 교체합니다.

모든 테이블은 RLS 및 직접 접근 거부 정책을 사용합니다. 브라우저는 로그인 후 `public.wordmaze_api`만 호출합니다. 실제 잔액·재고·보상 변경은 비공개 스키마의 제한된 트랜잭션에서 로그인 사용자를 확인하여 수행합니다. 익명 사용자의 RPC 실행 및 테이블 직접 쓰기는 금지합니다.

### 호스팅 후 로그인 주소 등록

실제 배포한 주소를 Supabase **Authentication → URL Configuration → Redirect URLs**에 추가해야 Google 로그인이 같은 앱으로 돌아옵니다. 예를 들어 Firebase에 나중에 배포하면 `https://wordmaze.web.app/`를 추가합니다. GitHub 하위 경로라면 그 경로까지 포함합니다. 기존 사이트 URL과 기존 앱의 허용 주소는 유지합니다. Google 제공업체는 기존 sudoku에서 사용하는 설정을 재사용합니다.

브라우저에서 모드 선택, 싱글 시작, 동물 선택 및 토끼 능력 이동을 확인했습니다. 현재 요청은 GitHub 업로드만 포함하므로 Firebase 배포 및 새 호스팅 주소의 로그인 왕복 검증은 진행하지 않았습니다.

## Firebase 나중에 배포하기

이 폴더의 `firebase.json`은 Hosting 사이트 `wordmaze`와 `dist/`를 가리킵니다. 실제 사이트가 속한 프로젝트를 확인한 다음 이 폴더에서 배포합니다. 루트 studio의 Firebase 설정·자동 배포 대상은 변경하지 않습니다.

```sh
npm ci
npm run build
firebase deploy --only hosting --project YOUR_CONFIRMED_PROJECT_ID
```

이번 GitHub 커밋은 `[skip ci]`를 사용하여 저장소에 있던 Firebase 자동 배포를 건너뜁니다. wordmaze 전용 자동 배포 워크플로는 추가하지 않았습니다.

## 검증 및 개인정보

- 로컬 자동 검사: 12 캐릭터 × 6 스테이지 × 2 영어 설정의 완료·저장, 능력, 개인 기록 갱신, 미로 경로, 음성인식 이벤트·오류 처리.
- 실제 Supabase: 합성 사용자로 12 캐릭터의 능력, 보상, 기록 경신, 구매, 잔액 부족, 중복 요청, 계정 격리 검사. 모든 검사 데이터는 트랜잭션에서 롤백합니다. 검사 SQL은 `tests/database.sql`입니다.
- 실제 마이크 인식 품질과 Google 로그인 왕복은 배포할 사용자 기기·호스팅 주소에서 추가 확인해야 합니다.

녹음 파일을 이 앱 서버에 업로드하거나 저장하지 않습니다. 브라우저 음성인식 제공업체로 음성이 전송될 수 있습니다. 멀티플레이는 인식 문자열을 RPC에 보내지만, DB에는 이름·도전 진행·시간·구매·별빛 내역만 보관합니다.
