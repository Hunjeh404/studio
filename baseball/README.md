# Animal League · KT–삼성 3D 동물 리플레이

2026년 한국시리즈 1차전(11월 3일 삼성 7 : 8 KT, 321구)과 2차전(11월 4일 삼성 3 : 2 KT, 연장 12회, 363구)을 선택해 3D 동물친구들로 재구성합니다. 한 팀은 한 동물로, KT는 고양이·삼성은 숫사자입니다(studio/public/chars 캐릭터).

## 실행과 전달

`dist/index.html` 하나에 경기 데이터·스타일·Three.js·구단 로고·실행 코드를 모두 넣습니다. 외부 요청, 로그인, CDN, 별도 서버 없이 브라우저에서 파일을 열어 실행할 수 있습니다. WebGL2를 사용할 수 있는 브라우저에서는 가속 렌더링을 사용하고, 없으면 동일한 실제 3D 메시를 Canvas 투영으로 표시합니다. 호환 모드에서는 평면별 명암과 낮은 프레임률이 나타날 수 있습니다.

## 화면과 연출

상단 Animal League 로고 옆에서 날짜와 참가팀으로 경기를 선택합니다. 소개 영역과 불필요한 주석은 삭제했습니다. 포수석·1루·2루·3루·전광판·볼 트래킹의 여섯 시점을 제공합니다. 고정 시점은 바꿀 때마다 투수석과 타자석 가운데를 바라보며 시작하고, 이후는 직접 조작합니다. 볼 트래킹은 공을 화면 중심에 둔 채 회전·확대·높낮이를 조절할 수 있습니다. 관중석은 개별 좌석·계단선·줄무늬를 생략한 단색 면으로 단순화하고, 경기장 경계와 바깥 윤곽만 구분합니다. 관중은 배치하지 않습니다.

홈런 장면은 18초입니다. 타격 클로즈업과 슬로모션 → 공을 따라가는 카메라와 별빛 폭죽 → 포수석 시점에서 주자들의 베이스 순환 순서입니다. 주자 이동을 공 추적 종료 이후로 지연해 포수석에서 전체 주루를 볼 수 있습니다.

마지막 플레이 뒤에는 경기 종료 장면을 자동 재생합니다. 공식 데일리 MVP(1차전 힐리어드, 2차전 페덱)는 같은 팀 선수들이 헹가레합니다. ‘오늘의 역적’은 기록된 수비 실책만 집계하고, 동률이면 해당 플레이의 실점과 마지막 발생 시점으로 판별합니다. 1차전 김현준, 2차전 오윤석입니다. 인물의 몸통·팔에 묶은 코믹한 줄은 전광판 상단 정중앙 고리에 연결합니다. MVP·전광판·전체 장면을 순서대로 반복해서 보여줍니다. ‘경기 종료 장면’ 버튼으로 바로 확인할 수 있습니다.

## 구장 축척

베이스 간격 90피트(27.4318m)를 기존 좌표의 18.3848 단위와 맞춰, 1m = 약 0.6702 단위로 통일했습니다. 좌·우 98m, 중앙 120m를 이 축척으로 적용해 이전의 지나치게 작은 외야를 넓혔습니다. 잔디와 관중석이 동일한 경계선을 공유하므로 그 사이에 빈 바닥이 없습니다. 파울 지역도 잔디로 채웁니다. 외야 중간 곡선과 파울 지역·관중석 세부 윤곽은 공표된 실측 설계도를 확보하지 못해 도식화한 추정 형태이며, 실제 구장 전체를 측량 복원한 것은 아닙니다.

치수 참고: [대전광역시의 전국 야구장 시설 비교표](https://daejeon.go.kr/drh/drhStoryDaejeonView.do?boardId=blog_0001&menuSeq=&ntatcSeq=1221515853&pageIndex=1), [Sport England / BaseballSoftballUK 성인 야구장 도면](https://sportengland-production-files.s3.eu-west-2.amazonaws.com/s3fs-public/natural-turf-baseball.pdf).

## 구현

- `src/engine.mjs`: 1차전 600개 사건을 372개 경기 장면으로, 2차전 706개 사건을 422개 경기 장면으로 묶습니다. 각 경기 뒤에 종료 연출 한 장면을 추가합니다. 자동 고의4구도 실제 투구와 구분합니다. 홈런, 주자별 진루, 도루·도루 실패, 폭투, 실책, 교체 및 비디오 판독을 처리합니다.
- `src/renderer3d.mjs`: 3D 구장, 카메라와 OrbitControls, PTS 기반 투구, 기록 기반 타격·송구·주루 동작입니다. 타격 후의 정확한 측정 궤적이나 야수 추적 좌표는 없으며 경로는 연출입니다.
- `src/models.mjs`: studio/public/chars의 블렌더 캐릭터(고양이·숫사자 GLB)를 불러와 studio와 같은 3단 카툰 재질을 입히고, 팀 색 유니폼·가슴 로고·등번호·방망이·글러브를 붙입니다.
- `src/gaze.mjs`: 공의 세계 좌표를 시선 목표로 사용합니다. 포수는 +Z의 투수 방향으로 서며, 수비수는 공을 향하고 달리는 선수는 이동 방향을 유지한 채 목을 돌립니다. 카메라 좌표를 시선 목표로 사용하지 않습니다.
- `src/animals.mjs`: 팀별 동물(KT 고양이, 삼성 숫사자)입니다.
- `src/effects.mjs`: 안타 별빛, 홈런 폭죽, 도루 스피드, 실책·폭투·포일·도루 실패의 책임 선수에게 코믹 벼락을 연결합니다. `LiveEffectBridge`도 같은 규칙을 사용하며 경기별 중복 입력을 억제합니다. 실시간 데이터 연결 자체는 포함하지 않습니다.
- `src/toon.mjs`, `src/toon-post.mjs`: `studio/public/index.html`에서 사용한 3단계 gradient와 깊이·법선 외곽선 후처리를 적용합니다. 경기장과 선수 미리보기가 같은 파이프라인을 사용합니다. WebGL에서는 색·깊이·법선을 분리 렌더링하고 마지막 화면에서 잉크 선을 합칩니다. 소프트웨어 경로에서는 같은 음영 단계와 메시 윤곽선을 직접 그립니다.
- `src/field.mjs`: 홈 뒤에서 1루가 오른쪽으로 보이도록 베이스·수비·카메라 좌표를 함께 정의합니다.
- `src/logos.mjs`: KT 공식 logo192.png와 삼성 공식 홈페이지 로고를 내장하고 점수판·모자·유니폼에 비율을 유지해 표시합니다.
- `src/software3d.mjs`: WebGL을 쓸 수 없는 환경을 위한 동일 메시의 소프트웨어 3D 투영기입니다.
- `src/data.json`, `src/data-20261104.json`: KBO 공식 중계·박스스코어·이닝 점수표와 네이버 투구 궤적을 대조한 실제 기록입니다. 네이버 포스트시즌 ID는 `77771103SSKT02026`, `77771104SSKT02026`입니다. 2차전은 모든 103개 타석·24개 반이닝·25개 안타·363구를 검사합니다.

## 검증

`npm test`는 321구·최종 점수·이닝별 득점·4개 홈런·도루와 도루 실패·실책 진루·교체 후 수비 배치·한 팀 한 동물 배정을 검사합니다. 테스트는 1루 방향·20개 안타 효과·4개 홈런 효과·실책 책임 선수·중복 입력도 검사합니다.

검사 브라우저의 WebGL이 비활성화돼 있어 새 GPU 후처리 파이프라인의 브라우저 실구동 검증은 제한됩니다. 소프트웨어 3D 경로와 재생 UI는 브라우저에서 검증합니다.
